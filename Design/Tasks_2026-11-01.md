### Why diagonals fail

1. Up is bound to Enter and Down to S, so the arrows only know left and right. S is also Medium.
2. `InputManager.ReadDash` fires on the first direction key pressed. With Space held, two arrows that land a frame apart give a straight dash, and the second arrow is ignored.

## Task 2: Two players on one keyboard

**Goal:** a playable layout for two people on one keyboard, shown to both before each game, and editable there.

### The clash to solve

The Task 1 layout has Player 1 on the arrows, which are Player 2's keys in a two-player game. So the vs-AI layout and the two-player layout must be saved separately: a new solo set, plus the existing `p1` / `p2` sets.

### Layout

Player 2 moves on the arrows with the left hand and attacks on the numpad with the right, so it needs a keyboard with a numpad. Arrows have no spare keys for a dash ring, so Player 2's diagonals are the modifier + two arrows, like the solo layout.

| Action | Player 1 | Player 2 |
|---|---|---|
| Move left / right | A / D | Left / Right arrows |
| Dash modifier | F | Numpad 0 |
| Dash up / down (one tap) | W / X | Up / Down arrows |
| Dash up-right / down-right | E / C (one tap) | Numpad 0 + Up or Down + Right |
| Dash up-left / down-left | Q / Z (one tap) | Numpad 0 + Up or Down + Left |
| Light / Medium / Heavy | H / J / K | Numpad 4 / 5 / 6 |
| Special modifier | L | Numpad + |
| Block + parry | O | Numpad 9 |
| Run | Hold the forward dash (F + walk key toward the opponent) | Same, with Numpad 0 |

**Decided:**

- **Run:** holding the forward dash rolls into a run. Press F + the key toward the opponent and keep both held.
- **One-tap dashes:** Q W E Z X C dash on a single tap, with no modifier. F is needed only with A / D, because those walk on their own. The Controls screen, the review screen and Help must all say this clearly.

Parry is the timed block raise, so one key covers both. The separate Defense key is not needed for play. Throw, Low and Stance do nothing in the game, so they stay unbound here.

Dash directions follow the screen, like walking: E is always up-right. It is only "forward" while Player 1 stands on the left. Task 3 deals with what happens when the fighters swap sides.
