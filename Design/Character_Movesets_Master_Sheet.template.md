# 🎮 CHARACTER MOVESET MASTER SHEET
## CRUCIBLE: Honorable Souls

Fill in ALL move names, damage, and properties for each character. This is your complete moveset bible.

---

## 📋 MOVE PROPERTY GUIDE

For each move, fill in:
```
NAME:           Creative name for the move
DAMAGE:         Base damage (10-50)
STAMINA COST:   Cost to perform (5-70)
STARTUP:        Frames before damage (1-30)
ACTIVE:         Hit window frames (1-15)
RECOVERY:       Recovery frames (5-40)
ARMOR PIERCE:   % bypass armor (0-100)
KNOCKBACK:      Push force (0-3.0)
HITSTUN:        Stun duration (0.05-0.5s)
PROPERTIES:     Special effects (e.g., "knockdown", "unblockable")
```
