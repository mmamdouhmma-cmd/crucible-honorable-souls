# CRUCIBLE: Honorable Souls — Downloads

This repository only hosts game builds. Get the latest version from
[Releases](https://github.com/mmamdouhmma-cmd/crucible-honorable-souls/releases/latest).

- **Windows:** download the `-Win64.zip`, unzip it somewhere you can write to (Desktop, Documents — not Program Files), run `Crucible.exe`.
- **Android:** download and install the `-Android.apk`.

Once installed, the game updates itself from the main menu.
