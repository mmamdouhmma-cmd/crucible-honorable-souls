# CRUCIBLE: Honorable Souls

1v1 3D fighting game. Unity **6000.4.4f1** (URP), C#. P1 on keyboard, P2 on a PS4/PS5 controller.

**Read `CLAUDE.md`** for the code layout, how combat works (frame data, hitboxes in world units,
hitstun), the animator parameters the code expects, conventions, and the session log.

## Open the project

1. Install Unity 6000.4.4f1 through Unity Hub.
2. Clone this repo and add the folder in Unity Hub. Unity regenerates `Library/`, `Temp/`, the
   `.csproj` files and the solution on first open; none of those are committed.
3. Open `Assets/_project/Scenes/testarena.unity` and press Play.

## What is not in git

| Path | Why |
| --- | --- |
| `Assets/Character model/` (~716 MB) | Rigged FBX characters with files over 100 MB. GitHub rejects them without Git LFS, so they stay local. Get them from the project owner; the scene references their prefabs. |
| `Assets/_Recovery/` | Unity crash-recovery scenes. |
| `.plastic/` | Plastic SCM state from an earlier VCS setup. Not used. |
| `Library/`, `Temp/`, `Logs/`, `UserSettings/`, `*.csproj`, `*.slnx` | Generated by Unity. |

## Code layout (short)

- `Assets/_project/Scripts/characters/` — `Fighter`, `FighterStats`, `FighterData`
- `Assets/_project/Scripts/combat/` — `CombatSystem`, `HitDetector`, `AttackData`, `DamageCalculator`
- `Assets/_project/Scripts/input/` — `InputManager`
- `Assets/_project/Scripts/config/BalanceConfig.cs` — global tuning constants
- `Assets/_project/Data/` and `Assets/_project/models/characters/p2/*.asset` — per-attack data
